# Getting started

Choose one execution boundary and follow its guide from start to finish.

```{toctree}
:maxdepth: 1

installation
quickstart
../how-to/runtime-images
```

- Use the local quickstart to validate a formal algorithm and Bundle without
  external storage or a remote cluster.
- Use Ray Jobs when a reachable cluster should own the process, logs, status,
  and cancellation boundary. Continue with the
  [Ray Jobs guide](../ray-jobs/index.md).
- Use the component guides after the first successful workflow.
