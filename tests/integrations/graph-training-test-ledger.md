The Docker Gate will run the existing official `graph` category as a regression
baseline and then submit a separate Core-only graph job using the fixed Core
Wheel. It will use a unique Compose project and preserve runner logs and
provenance under `/tmp/tributo-distributed-algorithm-it-*`.
